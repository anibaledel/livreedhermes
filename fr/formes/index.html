Les 128 formes des patterns unifiés

Chaque forme réunit quatre patterns : un hexagramme et son complément, dans les deux couples d’une famille. 128 formes × 4 = 512 patterns. Le code de la forme tient sur 7 bits : phase du yang, yin présent, classe de complément (5 bits).
