Après cet en-tête, concaténation des sorties des quatre commandes suivantes,
dans cet ordre. Le script sort en code 0 si tout est construit et magique,
en code 1 sinon : c'est une assertion, pas un rapport.

  python tools/construction.py --existence
  python tools/construction.py --ordres 2,4,6,8,10,14,18,22,26,30,34,38,42,46,50
  python tools/construction.py --toutes
  python tools/construction.py --echantillon 20 --ordres 6,10,14,18,22,26,30

Le cas négatif n = 2 est CONTRÔLÉ et non déduit : les 256 étiquetages de
l'ordre 2 sont énumérés, aucun n'est magique, et les 24 carrés 2×2 normaux
le sont aussi, aucun n'a lignes et colonnes égales. L'échec du critère II à
cet ordre, invoqué par une version antérieure, ne prouverait que l'absence de
croix ansée : II est une condition de la figure, pas de la magicité.

Deux résultats. LE THÉORÈME POSITIF : à n = 2m ≥ 6 avec m impair, TOUTE figure
candidate est réalisable ; avec le théorème négatif de `parite.py`, la
classification est complète et le nombre de FIGURES de croix ansée vaut
2^(m²−3m+1) à m impair, 0 à m pair. LE COROLLAIRE D'EXISTENCE COMPLÈTE : le
protocole admet un étiquetage magique à tout ordre pair n ≥ 4 — croix ansée
canonique à n ≡ 2 (mod 4), motif classique à deux classes B/R à n ≡ 0 (mod 4) —
et l'ordre 2 est le seul ordre pair impossible. Le motif B/R ne vérifie pas la
condition I : il est magique sans porter de croix ansée, et c'est la preuve que
les deux questions sont distinctes.
