# Jeu unifié de La Livrée d’Hermès — 96 plaques

Ce dépôt réunit un sous-ensemble du jeu complet des 360 calques. Il permet de composer les 512 grilles unifiées, soit 256 paires de phases. Les quatre familles retenues sont {YANG}, {YANG-MUT}, {YIN, YANG} et {YIN, YANG-MUT}. Chacune se décline en quatre couches de six niveaux.

Les 96 fichiers sont fournis dans chacun des trois formats : SVG, STL et 3MF. Les modèles reprennent les fichiers du jeu complet sans modification. Le manifeste donne leur correspondance avec le référent et les empreintes des fichiers sources de ce référent ; ces empreintes ne sont pas celles des exports STL et 3MF.

Le protocole explique comment choisir la famille, le couple fixe/mut et les six niveaux, puis obtenir le complément. Les contrôles sur le référent vérifient le dénombrement, l’échange de deux teintes et le demi-décalage.
